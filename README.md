# 🧬 Bio-Luminescent AI HUD

> A futuristic Bio-Luminescent AI HUD interface built with pure HTML5 and CSS3.

A cyberpunk-inspired futuristic AI dashboard featuring glowing neon effects, animated rings, a central AI core, data panels, holographic elements, and smooth CSS animations.

Designed to showcase what can be achieved using **HTML5 + CSS3 + SVG filters** without external libraries.

---

## ✨ Features

- 🧠 Futuristic AI Core Interface
- 💡 Bio-Luminescent Neon Glow Effects
- 🔄 Animated Circular HUD Rings
- 🌐 Cyberpunk Perspective Grid
- 📊 Futuristic Data & Metric Cards
- ⚡ Smooth CSS Animations
- 🎨 SVG Filter Effects
- 📱 Responsive Layout
- 🖥️ Pure HTML & CSS
- 🚫 No External Libraries
- 🚀 Works Directly in the Browser

## 🎨 UI Components

The HUD contains several futuristic interface elements:

### 🧠 AI Core

A glowing central AI orb represents the main intelligence system.

### 🔄 Animated HUD Rings

Multiple rotating circular rings create a futuristic scanning effect around the AI core.

### 📊 Data Panels

Side panels display futuristic system information, metrics, and status indicators.

### 🌐 Cyber Grid

A perspective-based animated grid creates the sci-fi environment behind the interface.

### 💡 Neon Effects

CSS shadows, gradients, and SVG filters are used to create the glowing bio-luminescent appearance.

## ▶️ How to Run

### Option 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The HUD will open in your browser.

### Option 2 — VS Code

1. Open the project in **Visual Studio Code**.
2. Open `index.html`.
3. Use a local development server such as **Live Server**.
4. Open the generated local URL in your browser.
